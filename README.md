# WingFuel.co — Aviation Fuel & Airport Ground Operations Hub

![WingFuel.co Logo](/public/assets/aistudio/WingFuel_Orbit_Logo_e3f91314.png)

**WingFuel.co** is a professional technical platform built for aviation refueling engineers, airport ground operation managers, pilots, and fuel quality control specialists.

---

## ⚡ Features & Capabilities

- **ATF Density & Temperature Calculator**: Convert observed density & temperature to standard reference conditions (15°C / 60°F) and compute mass/volume conversions.
- **Aviation News Aggregator**: Real-time news feeds with AI summaries for regulations, SAF (Sustainable Aviation Fuel), and airport operations.
- **Technical Knowledge Base**: Articles on fuel sampling, water detector capsules, hydrant systems, and filter separators.
- **Digital Products Store**: Instant download templates for ATF quality control logs, inspection checklists, and density calculation spreadsheets.
- **User Accounts & Bookmarks**: Firebase Authentication (Google & Email/Password) with custom bookmarks saved locally and in user profiles.
- **Dual Theme Support**: Light & Dark mode toggle across the entire application.
- **AdMob Integration**: Mobile-friendly AdMob banner integration (`pub-2011257851590169`).

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS v4, Lucide Icons
- **Backend & Auth**: Firebase Firestore & Firebase Auth (`wingfuel-1f48d`)
- **CI/CD**: GitHub Actions deploying automatically to Firebase Hosting
